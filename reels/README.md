# Reel Production Library

This library contains 28 record-ready Reels. Career claims come from `CAREER_FACTS.md`; voice, audience, and pillars come from `BRAND_VOICE.md`.

## Workflow

1. Open the Reel folder and review `CONTENT.md`.
2. Add screenshots, B-roll, images, references, and audio to its `materials/` folder.
3. Record the spoken script conversationally; do not add unsupported metrics or confidential details.
4. Burn captions into the edit and emphasize the hook and closing line on screen.

## Brand rules for every Reel

- One primary audience, one pillar, one main idea.
- Natural spoken Egyptian Arabic; English only for terms that are normally said in English.
- Start with the idea, not a greeting. No CTA unless it fits.
- Personal experience appears only at the level `CAREER_FACTS.md` supports. Scenarios introduced with "تخيل" are illustrations, not real incidents.
- AutoFlow is always described as a personal prototype on localhost that never launched.
- Each Reel works on its own, even when it shares a weekly topic with a long-form video.
