# Reel Production Library

This library contains 28 record-ready Reels based on `CAREER_FACTS.md`.

## Workflow

1. Open the Reel folder and review `CONTENT.md`.
2. Add screenshots, B-roll, images, references, and audio to its `materials/` folder.
3. Record the spoken script conversationally; do not add unsupported metrics or confidential details.
4. Burn captions into the edit and emphasize the hook and closing line on screen.
