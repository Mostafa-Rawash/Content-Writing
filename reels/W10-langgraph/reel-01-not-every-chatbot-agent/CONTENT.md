## Spoken script

لو النظام بياخد سؤال ويرسل Prompt ويرجع إجابة، ده Chat Interface مع Model. الـAgent الحقيقي عنده State، يختار خطوة تالية، يستخدم Tools، ويتعامل مع نتيجة كل خطوة. في نظام الدعم اللي بنيته بـLangGraph، الـflow كان يوضّح السؤال، يصنّفه، يسترجع المعرفة، يولّد الإجابة، ثم ينقدها ويصححها عند الحاجة. القيمة مش في كلمة Agent؛ القيمة في Workflow يمكن فهمه ومراقبته.

## Closing

استخدم Agent لما القرار متعدد الخطوات—مش لمجرد التسويق.

State + tools + controlled workflow = agentic behavior.
