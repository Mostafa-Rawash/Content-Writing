# Frontend vs Backend ببساطة

- Publish: 2027-02-07
- Duration: 35–45 seconds
- ClickUp: https://app.clickup.com/t/123mehfy7en

## Hook

Frontend وBackend ببساطة—من غير تعريفات مدرسية.

## Spoken script

الـfrontend هو الجزء اللي المستخدم يتفاعل معاه، لكنه مش مجرد شكل. هو مسؤول عن تجربة الإدخال، عرض الحالة، والتعامل مع الاستجابة. الـbackend هو المكان اللي يحمي القواعد: مين مسموح له يعمل إيه، البيانات تتخزن إزاي، والعمليات تتنفذ بأي ترتيب. اشتغلت على الاثنين، واتعلمت إن الفصل الحقيقي مش “شكل مقابل كود”؛ هو “تفاعل عند العميل مقابل قواعد موثوقة على السيرفر.”

## Closing

لو قاعدة مهمة للأمان أو البيانات، ما تعتمدش على الـfrontend وحده.

## Caption

Frontend guides the interaction; backend enforces the truth.
